# School Data Skill

這個技能協助在新增課程或活動時，自動同步更新學校資料（`schools.json`）。

## 功能

當新增課程或活動時，如果發現是新的帆船學校，這個技能會：
1. 自動提取學校資訊（名稱、地區、認證等）
2. 生成符合格式的學校資料
3. 提示您確認是否要新增到 `schools.json`

## 使用方式

### /school-check "學校名稱"

檢查學校是否已存在於 `schools.json` 中，若不存在則提供新增建議。

**範例**：
```
/school-check "台中帆船學校"
```

### /school-add "學校名稱" "地區" "認證" "描述"

自動新增學校到 `schools.json`。

**範例**：
```
/school-add "台中帆船學校" "台中" "ASA,IYT" "台中地區專業帆船教學"
```

### /school-sync

檢查所有課程和活動中的學校，找出未定義的學校並建議新增。

## 學校資料格式

```json
{
  "id": "唯一識別碼（小寫，無空格）",
  "name": "學校全名",
  "shortName": "簡短名稱（4-8 字）",
  "description": "學校描述",
  "certs": ["認證類型陣列"],
  "locations": ["地點陣列"]
}
```

## 最佳實踐

1. **新增課程時**：先使用 `/school-check` 確認學校是否已存在
2. **新增活動時**：同樣檢查主辦單位是否已在學校資料中
3. **重複檢查**：使用 `/school-sync` 定期檢查是否有遺漏的學校

## 自動生成規則

- `id`: 將學校名稱轉換為小寫，移除空格和特殊字元
- `shortName`: 取學校名稱前 4-8 個字
- `certs`: 從課程的 `organization` 欄位提取（ASA, IYT, TSA 等）
- `locations`: 從課程的 `location` 欄位提取

## 注意事項

- 確保 `schools.json` 中的學校名稱能與課程/活動的 `unit` 欄位完全匹配
- 新增學校前先檢查現有資料，避免重複
- 地區建議使用：北台灣、中台灣、南台灣、東台灣
